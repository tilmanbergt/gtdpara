# Getting started

## Install

1. Download the newest `gtdpara-x.y.z.snplg` from the Releases page on GitHub (github.com/tilmanbergt/gtdpara).
2. Copy it to your Supernote and install it as a plugin. Your firmware needs plugin support.
3. Open any note, open the plugin sidebar and tap the gtdpara icon.

To update later, install the newer file over the old one. Read the **Upgrade notes** in "What's new" (Settings → About) first. If a message says the old version is still loaded, tap **Restart** once.

## First setup

gtdpara works with four folders inside your `Note` folder:

- `1 Projects`: one folder per project
- `2 Areas`: one folder per area of responsibility, plus `0 Inbox` for the Inbox
- `3 Resources`: reference material
- `4 Archive`: finished projects

These names are only defaults. Change them in **Settings → Folders** if you already have a PARA structure, then tap **Save**.

Want to look around first without touching your own files? Go to **Settings → Advanced** and tap **Create demo space**, then switch to the Demo profile. See [Profiles and the demo space](profiles-and-demo.md).

## The tabs

- **Projects** and **Areas**: all your projects and areas, create new ones
- **Daily**: today and tomorrow - meetings, the todos that matter now, your daily focus
- **Week** and **Month**: plan the week and the month, set focus and goals
- **Inbox**: everything captured but not yet filed
- **Current**: the project or area you opened last, with its todos, meetings, files and notes
- **Review**: the Weekly Review, one step at a time
- **Settings**: folders, focus counts, Tag Rules, advanced options, About

**?** opens this help, starting at the page for the tab you are on. **✕ Close** in the help closes it again; the tab behind it stays exactly as it was. 🔄 reloads the current tab. ✕ closes the plugin.

## Opening gtdpara from a note

When you open gtdpara from a note that belongs to a project or area, it opens that project on the **Current** tab. From any other note it opens **Daily**. If you opened a note from inside gtdpara and come back from that same note, gtdpara returns to the screen you left.

## A first day with gtdpara

1. Create one or two projects on the **Projects** tab.
2. Open a project and add a few todos with Quick Add. Mark the next step with the **Next** chip.
3. On **Daily**, pick the project into your daily focus. Its next steps now appear there.
4. At the end of the week, walk through the **Review** tab.
